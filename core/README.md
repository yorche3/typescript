## 🧪 Convenciones / Conventions

**ES:** Los scripts independientes se compilan con `tsc` y se ejecutan con Node.js. Los proyectos tipo librería usan Jest y `ts-jest`, con código en `src/` y pruebas en `test/`.

**EN:** Standalone scripts are compiled with `tsc` and run with Node.js. Library-style projects use Jest and `ts-jest`, with code under `src/` and tests under `test/`.
